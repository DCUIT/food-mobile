# HƯỚNG DẪN CHẠY FOOD APP FLUTTER + FLASK

## Backend (API)
```
cd backend
pip install -r requirements.txt
python app.py
```
*Chạy http://localhost:5000*

## Frontend (Flutter)
```
flutter pub get
flutter run
```
Chọn emulator/Chrome/device.

## Demo
- Login: `admin` / `123`
- Browse → Cart → Thanh toán COD
- Admin: Quản lý món/order

**Hot reload `r` trong flutter run.**

## Lệnh 1-click Backend
`backend/run.bat`

## Fix lỗi
`flutter clean && flutter pub get`

App ready! 🎉
